# Contributing to Stroku

Stroku accepts contributions through forks and pull requests. Direct write
access is not required.

## Before opening a pull request

1. Fork the repository and create a focused branch.
2. Follow the README and test instructions for the component you changed.
3. Keep changes scoped and explain the user-visible behavior.
4. Do not include credentials, auth keys, private-network addresses, local
   machine paths, build output, discarded snapshots, or unlicensed assets.
5. Add or update tests when behavior changes.

Pull requests must pass the required checks and receive maintainer approval
before they can merge into `main`.

## Media, trademarks, and copied material

Stroku is an independent project. Do not copy Stremio web assets, logos,
screenshots, database material, or source code into a contribution unless you
have permission to redistribute them. Use original or clearly licensed assets.

By submitting a contribution, you agree that it may be distributed under the
repository license.
