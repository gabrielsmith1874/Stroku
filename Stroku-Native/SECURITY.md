# Security policy

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting for this repository when it is
available. Otherwise, open a private support request through GitHub and include
only the minimum details needed to reproduce the issue.

Do not post Stremio auth keys, add-on credentials, debrid tokens, Roku
developer passwords, signing keys, or private network information in issues,
pull requests, logs, screenshots, or discussions.

The project does not accept secrets in source code, test fixtures, or example
configuration.
