# Security policy

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting for this repository when it is
available. Otherwise, contact the maintainer through a private GitHub support
request and include only the minimum reproduction details.

Never post Stremio auth keys, add-on credentials, debrid tokens, Roku developer
passwords, signing keys, private network information, or unredacted logs in
issues, pull requests, or discussions.
